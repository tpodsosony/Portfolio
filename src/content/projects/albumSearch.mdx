# Project Purpose

This was a project created in React using LastFM's public API to search for artists and their respective albums. As my first array into React, it was a challenge set for myself to learn React, while also using LastFM's API for the first time.

As someone who listens to a lot of music, I figured a project that involved music artists would get my attention and a search of their top hits seemed like the obvious choice to me. 
[The link to the site can be found here](https://mmrlkn.csb.app/).

# What I learned

Creating this taught me how to use API keys, to navigate JSON files with React's tools, and how to create a basic HTML page in React.
